# Variant Annotation and Reporting

This section documents the variant annotation and reporting stage of the Exome Sequencing Data Analysis workflow.

After variant calling and VCF normalisation, the identified variants were analysed to understand their possible functional effects and identify potential disease-causing variants.

This stage includes:

1. Variant annotation with functional genomic effects
2. Generating a GEMINI database for efficient variant queries
3. Candidate variant detection based on the family inheritance pattern
