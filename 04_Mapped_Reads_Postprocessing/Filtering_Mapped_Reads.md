# Filtering Mapped Reads

## Objective

After read mapping, three BAM files were obtained for the father, mother, and proband.

Before variant calling, the mapped reads were filtered to retain only reads for which:

- The read itself was mapped to the reference genome.
- Its paired mate was also mapped to the reference genome.

This filtering step helps retain confidently mapped paired-end reads for downstream analysis.

---

## Why Was Filtering Performed?

Although the mapped BAM files could potentially be used directly for variant calling, the Galaxy tutorial recommends performing basic mapped-read post-processing to obtain a more accurate representation of the variants present in the samples.

The FreeBayes variant caller used later in the workflow requires only minimal post-processing.

Therefore, the first post-processing step was to retain paired-end reads where both reads had successfully mapped to the reference genome.

This provides additional confidence that the reads are less likely to represent:

- Non-human contaminant DNA
- Sequencing artefacts
- Unreliably mapped read pairs

---

## Tool Used

**Samtools view**

The `Samtools view` tool was used to filter the mapped BAM datasets.

---

## Input Data

The following three mapped BAM files generated by **Map with BWA-MEM** were used:

- Father mapped reads
- Mother mapped reads
- Proband mapped reads

All three datasets were selected simultaneously using the multiple dataset option.

---

## Filtering Parameters

The following settings were used:

### SAM/BAM/CRAM Dataset

**All three mapped reads datasets of the family trio**

These were the outputs generated by the BWA-MEM read mapping step.

### What Would You Like to Look At?

`A filtered/subsampled selection of reads`

### Configure Filters

Under:

**Exclude reads with any of the following flags set**

The following flags were selected:

- `Read is unmapped`
- `Mate is unmapped`

---

## What Do These Filters Mean?

The filters remove reads when:

### Read is unmapped

The sequencing read itself could not be successfully mapped to the reference genome.

### Mate is unmapped

The paired read associated with that sequencing read could not be successfully mapped to the reference genome.

By excluding both categories, the resulting BAM files contain reads for which:

Read is mapped
      +
Mate is mapped
