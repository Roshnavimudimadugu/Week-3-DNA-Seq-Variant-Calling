# Generating FreeBayes Calls

## Objective

After read mapping and mapped-read post-processing, the processed BAM files from the father, mother, and proband were used for variant calling.

The objective of this step was to identify sequence variants by comparing the sequencing data from the family trio with the human reference genome.

---

## What Is Variant Calling?

Variant calling is the process of identifying positions where the sequenced samples differ from the reference genome.

The workflow aimed to identify variants such as:

- SNPs (single-nucleotide polymorphisms)
- Indels (insertions and deletions)
- MNPs (multi-nucleotide polymorphisms)
- Small complex variants

---

## Tool Used

**FreeBayes**

FreeBayes is a Bayesian genetic variant detector designed to identify small genetic polymorphisms from sequencing data.

An important feature of this analysis was that variants and genotypes were called jointly across the family trio.

---

## Input Data

The input consisted of the duplicate-removed BAM files generated by the previous RmDup step:

- Father — processed BAM file
- Mother — processed BAM file
- Proband — processed BAM file

All three datasets were analysed together.

---

## FreeBayes Parameters

The following settings were used according to the Galaxy tutorial.

### Reference Genome Source

**Locally cached**

### Run in Batch Mode

**Merge output VCFs**

### BAM Datasets

All three mapped and fully post-processed BAM datasets from the family trio:

- Father
- Mother
- Proband

### Reference Genome

**Human: hg19**

### Limit Variant Calling to a Set of Regions

**Do not limit**

### Parameter Selection Level

**1. Simple diploid calling**

---

## Why Was Joint Variant Calling Used?

Instead of calling variants separately for each individual, the three family members were analysed together.

Joint variant calling allows the genotypes of the:

- Father
- Mother
- Proband

to be represented together for each detected variant.

This is important for downstream family-based analysis because the genotype of the affected child can be compared with the genotypes of both parents.

---

## Output

FreeBayes produced a **multisample VCF file** containing variants detected across the family trio.

For every detected variant, the VCF records information including:

- Genomic position of the variant
- Reference allele
- Alternate allele
- Variant quality
- Variant-related information
- Genotype information for the father
- Genotype information for the mother
- Genotype information for the proband

---

## Understanding the VCF Output

The Variant Call Format (VCF) is a tab-separated text format used to store genetic variant information.

Each variant is represented on a separate line.

The VCF contains important columns such as:

| Column | Description |
|---|---|
| `#CHROM` | Chromosome containing the variant |
| `POS` | Position of the variant |
| `ID` | Variant identifier |
| `REF` | Reference allele |
| `ALT` | Alternate allele |
| `QUAL` | Variant call quality |
| `FILTER` | Filtering status |
| `INFO` | Additional variant information |

The sample columns contain genotype information for the father, mother, and proband.

---

## Variant Call Quality

The variant call quality is stored in the `QUAL` column.

This value represents the reliability of the detected variant.

The values are **Phred-scaled**, similar to sequencing base quality scores.

A higher value generally indicates greater confidence that the variant is real.
